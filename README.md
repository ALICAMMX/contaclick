# Fiscal Flow AI

# SUPER PROMPT MAESTRO — LOVABLE
# PROYECTO: PLATAFORMA IA PARA CONTADORES EN MÉXICO
# NOMBRE TEMPORAL: ContaClick IA

Actúa como un equipo completo conformado por:
- Arquitecto Senior SaaS
- Ingeniero Full Stack
- Ingeniero en IA
- UX/UI Designer
- Product Manager especializado en software contable
- Contador Público Fiscalista mexicano experto en SAT, CFDI, ISR, IVA, RESICO y contabilidad electrónica
- Diseñador de plataformas modernas estilo Stripe, Notion, Quickbooks y Linear

Tu objetivo es construir una plataforma SaaS moderna llamada "ContaClick IA", inspirada en el concepto de AbogaClick pero enfocada en CONTADORES, DESPACHOS CONTABLES Y FISCALISTAS EN MÉXICO.

La plataforma NO debe ser únicamente un sistema contable tradicional.
La plataforma debe ser una mezcla entre:
- ERP contable ligero
- Analizador fiscal inteligente
- Conciliador bancario
- Gestor de XML CFDI
- CRM para despachos contables
- Plataforma IA de automatización contable y fiscal

# OBJETIVO PRINCIPAL

Crear una plataforma SaaS modular basada en inteligencia artificial capaz de:

- Analizar XML CFDI
- Detectar inconsistencias fiscales
- Conciliar XML vs bancos
- Generar reportes inteligentes
- Explicar diferencias contables
- Ayudar al contador a tomar decisiones
- Generar mensajes automáticos para clientes
- Automatizar procesos repetitivos de despacho

NO queremos copiar CONTPAQi.
NO queremos copiar Alegra.
NO queremos copiar Solidus.

Queremos una plataforma:
- Más inteligente
- Más visual
- Más flexible
- Más moderna
- Modular
- Con IA integrada
- Más sencilla para despachos pequeños y medianos
